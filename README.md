## ⏱️ Important Complexities

| Algorithm            | Time Complexity |
| -------------------- | --------------- |
| Linear Search        | O(n)            |
| Binary Search        | O(log n)        |
| Bubble Sort          | O(n²)           |
| Selection Sort       | O(n²)           |
| Insertion Sort       | O(n²)           |
| Dijkstra's Algorithm | O(V²)           |
| BFS                  | O(V + E)        |

## ⚙️ How to Run

Compile a C program using:

```bash
gcc filename.c -o program
```

Run using:

```bash
./program
```

For example:

```bash
gcc week-05/shortest_path.c -o shortest_path
./shortest_path
```
